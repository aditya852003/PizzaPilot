# **App Name**: Pizza Pal

## Core Features:

- Authentication: Securely authenticate users via name, phone number, or Google Sign-In, generating a unique session token.
- Chatbot Ordering: Engage users in a natural conversation to take pizza orders, clarifying item details and quantities.
- Smart Upselling: Suggest one relevant add-on per item (e.g., extra cheese, cold drink) to maximize profitability without being pushy; uses reasoning tool to apply constraints.
- Order Confirmation: Summarize the full order and confirm with the customer before generating the bill.
- Bill Generation: Generate a receipt-style bill including customer details, order ID, itemized list with prices, and total amount.
- Simulated Payment: Present payment options (cash/online) and assume payment success upon confirmation.

## Style Guidelines:

- Primary color: Saffron (#FFB830) to evoke the warmth of Italian and Desi cuisine.
- Background color: Light cream (#FAF2E7), a very desaturated version of the primary color.
- Accent color: Burnt Orange (#D47C00) for call-to-action buttons.
- Secondary accent color: Fiery Red (#FF5733) to highlight special offers and discounts.
- Font pairing: 'Belleza' (sans-serif) for headlines and 'Alegreya' (serif) for body text, reflecting both personality and elegance.
- Use warm, friendly icons related to pizza, Italian culture, and desi elements.
- Clean, professional bill layout with clear itemization and readable font sizes.
- Subtle animations when adding items to the order or confirming payment.
- A spicy animation for the upselling feature
